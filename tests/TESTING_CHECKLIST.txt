TESTING PRIORITY
================================================================================

HIGH PRIORITY (Start Here):
1. Data models (SessionData, SmartDotData, EncoderData, HeatData)
2. DataController (core business logic)
3. CloudAPI (data persistence)
4. iMotor/Motor implementations (hardware control)

MEDIUM PRIORITY:
1. SmartDot sensor handling
2. UI page navigation
3. Graph display

LOW PRIORITY (Nice to Have):
1. Dialog edge cases
2. Logging edge cases

NOTES FOR TESTING
================================================================================

- Use pytest fixtures for setup/teardown
- Mock cloud API calls in unit tests
- Use mock GPIO for motor tests
- Use mock SmartDot for sensor tests
- Integration tests can use real API (with test account)
- Use pytest-qt for PyQt6 UI tests
- Aim for >80% code coverage
- Run tests in CI/CD pipeline
- Keep tests isolated and independent
