### What's on this page

- SmartDot roles in Shot Mode, Diagnostic Mode, Shot View, and Analysis Mode.
- Connection workflow and session lifecycle expectations.
- Data quality practices for repeatable results.

### How to use this page

1. Connect SmartDot before starting shot/diagnostic capture.
2. Keep device placement and orientation consistent between sessions.
3. Verify active data flow in graph pages during runs.
4. Disconnect cleanly when done or before changing devices.

### Warnings

> **Do NOT** move or remount the SmartDot mid-session
> when you need comparable data.
>
> **Do NOT** assume old buffered samples
> belong to the current run.
>
> **Do NOT** ignore disconnect notifications
> while motors continue running.
